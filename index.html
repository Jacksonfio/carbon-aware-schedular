Carbon-Aware Deployment Scheduler

A GitHub Actions plugin that delays non-urgent CI/CD deployments to AWS regions with the lowest real-time carbon intensity, then tracks the saved CO2 on a live dashboard.

GitHub Actions AWS Python React Terraform Sustainability

How it works

  1. Fetches real-time grid carbon intensity (gCO2/kWh) for the target AWS region via Electricity Maps API
  2. Scores the deployment and decides: DEPLOY_NOW, HOLD, or OVERRIDE
  3. Held jobs queue in AWS SQS; a Lambda poller re-checks every 30 min and auto-triggers when the grid is green
  4. Every deployment logs a carbon record to S3 → visible on the React dashboard

Carbon Scoring

< 150 gCO2/kWh → Very green → DEPLOY_NOW

150–250 gCO2/kWh → Acceptable → DEPLOY_NOW

250–400 gCO2/kWh → Hold zone → HOLD

> 400 gCO2/kWh → High carbon → HOLD

urgency = true → Any score → OVERRIDE
